# Personal Expense Tracker
A beginner-friendly Java console application that helps users calculate their monthly expenses and remaining balance.
## Features
- Enter monthly income
- Add any number of expense categories
- Calculate total expenses
- Calculate remaining balance
- Validate income and expense amounts
- Save the expense summary to a text file
## Technologies Used
- Java
- Scanner for user input
- Arrays and loops
- File handling using `FileWriter`
- Exception handling using `try-catch`
## How to Run
1. Install the Java Development Kit (JDK).
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Compile the program:
   javac ExpenseTracker.java
5. Run the program:
   java ExpenseTracker
## Output
The program displays the expense categories, total expenses, and remaining balance. It also saves the summary to `expenses.txt`.
## Learning Outcomes
This project demonstrates Java fundamentals, arrays, loops, input validation, calculations, and file handling.
